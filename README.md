# 训练实验步骤可视化

一个纯前端、可离线使用的**训练结果散点图**绘制与编辑工具。用于可视化机器学习实验中不同模型（步骤）在不同训练时间下的得分对比，以及模型之间的继承 / 来源关系。

## 功能特性

- **散点图**
  - 纵轴为得分，固定范围 50–90（带刻度）
  - 横轴为训练时间，每个训练时间一列；同一训练时间下多个点落在同一列
- **来源连线**
  - 每个点可指定「来源实验（模型名）」，有来源时从该模型（取该模型得分最高的点）画一条带箭头的线指向本点
  - 无来源则不画线
- **手动编辑**
  - 每个点手动输入：模型名、训练时间、得分、来源实验
  - 支持添加 / 删除 / 修改，实时刷新图表
- **自定义样式**
  - 点颜色：可自动（按模型名配色）或自定义
  - 线颜色：可自动（跟随点颜色）或自定义
  - 线型：实线 / 虚线
- **横轴交互**
  - 横轴训练时间可拖动改变顺序，不拖动则按输入顺序
  - 模型名显示在点上方，得分显示在点下方，训练时间「横着」显示在横轴下方
- **显示调节**
  - 横轴字号：6–48 实时调节横轴下方训练时间字号
  - 纵轴字号：6–48 实时调节纵轴刻度数字与「得分」标签字号
  - 点标签字号：8–24 实时调节点上方两行标签字号
  - 横轴比例：30%–500%，调整各训练时间列的间距（超宽时图表横向滚动）
  - 图表标题：可在图下方添加标题，并调节标题字号（10–32）
- **数据持久化**
  - 数据与显示设置自动保存到浏览器 localStorage，刷新不丢失
- **导入 / 导出**
  - JSON 导入 / 导出
  - 图表导出为 SVG

## 使用方法

### 方式一：直接打开（离线）

双击 `index.html`，用任意现代浏览器打开即可，无需联网、无需安装任何依赖。

### 方式二：GitHub Pages

在仓库设置中开启 Pages（根目录），即可通过 `https://<用户名>.github.io/<仓库名>/` 在线访问。

## 数据格式

每个数据点包含字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `experiment` | string | 模型名（点标识，点上方第一行显示） |
| `trainingTime` | string | 训练时间（横轴维度，决定该点所在列） |
| `score` | number | 得分（50–90，超出自动修正） |
| `source` | string | 来源模型名（空字符串 = 无来源，不画连线） |
| `color` | string | 点颜色（十六进制，空 = 自动按模型名配色） |
| `lineColor` | string | 连线颜色（空 = 自动跟随点颜色） |
| `lineStyle` | string | 线型：`solid`（实线）/ `dashed`（虚线） |

完整示例见 [`sample-data.json`](sample-data.json)，可在页面右上角通过「导入」按钮加载。

## 技术栈

原生 HTML + CSS + JavaScript（SVG 自绘），无任何第三方依赖。
